# English C1 — интерактивный учебник грамматики

Одностраничное веб-приложение: вся грамматика английского, нужная для перехода B1 → C1.
Без бэкенда, без сборки — статичный HTML/CSS/JS, работает офлайн после первой загрузки
(кроме шрифтов с Google Fonts).

42 главы в 13 модулях — от базовых времён, артиклей и предлогов до conditionals, passive,
reported speech, modals, relative/participle clauses и продвинутых C1-конструкций (инверсия,
cleft sentences, subjunctive, gerund/infinitive, causative, дискурсивные маркеры, emphatic do).

Последние три модуля закрывают не грамматику, а остальные слои разрыва B1 → C1:
коллокации и естественность сочетаний, регистр (разговорный / нейтральный / формальный,
хеджирование, деловая вежливость), словообразование и ложные друзья.

Главы, которые прямо связаны с реальными ошибками ученика (личный файл правил, в этот репозиторий
не входит), помечены бейджем — с них стоит начинать. У каждой главы — объяснение по-русски, примеры,
и мини-тест на самопроверку (multiple choice / заполнение пропуска) с мгновенной проверкой на
клиенте.

Заучивание слов карточками — отдельная задача, здесь не покрыта: учебник объясняет системные
закономерности лексики, а набор словарного запаса ведётся отдельно.

## Как открыть

Открыть `index.html` напрямую в браузере (двойным кликом) не получится из-за `file://`
ограничений на загрузку `<script>`-тегов в некоторых браузерах. Нужен любой локальный статический
сервер:

```bash
npm run serve   # http://localhost:8010, использует python3 -m http.server
```

или задеплоить папку целиком как статический сайт (GitHub Pages и т.п.) — тогда открывается и
с телефона.

Прогресс (какие главы отмечены пройденными) сохраняется в `localStorage` браузера.

## Проверка контента

```bash
npm test
```

Прогоняет схему всех `content/*.js` файлов: уникальность id, обязательные поля, форма квизов.
Не проверяет грамматическую корректность — это ответственность автора контента, см.
`content/README.md`.

## Структура

- `index.html`, `style.css`, `app.js` — движок: навигация, роутинг по `#hash`, прогресс, квизы.
- `content/*.js` — по одному файлу на модуль (или несколько модулей), контент.
- `content/README.md` — схема главы для добавления нового контента.
- `test/validate.js` — схема-тест.
