# Схема файлов контента

Каждый `content/*.js` — самостоятельный файл. Загружается `<script>`-тегом в `index.html`
СТРОГО в порядке модулей 1→10 (порядок тегов = порядок модулей в сайдбаре). Каждый файл
пушит массив объектов-глав в общий `window.GRAMMAR_CHAPTERS`:

```js
window.GRAMMAR_CHAPTERS = window.GRAMMAR_CHAPTERS || [];
window.GRAMMAR_CHAPTERS.push(
  {
    module: 'Модуль 5. Conditionals',   // группировка в сайдбаре; порядок = порядок первого появления
    id: 'conditionals-zero-first',       // уникальный slug на ВСЕ файлы, латиница+дефисы, без пробелов
    title: '5.1 Zero & First Conditional', // с номером для порядка внутри модуля
    focus: 'high',                        // 'high' | 'medium' | не указывать вообще (undefined)
    focusNote: 'Правило 26 — путаница will/going to тоже здесь всплывает.', // короткая строка, видна как врезка
    intro: `
      <p>HTML-разметка объяснения. Разрешены p/ul/ol/li/strong/code/table/thead/tbody/tr/th/td.</p>
      <p>Каждый пример — <strong>пара</strong> (английское предложение + при необходимости перевод),
      НЕ просто список английских фраз без контекста.</p>
    `,
    mistakes: [ // НЕОБЯЗАТЕЛЬНО — только если пункт реально подкреплён rules.md, не выдумывать
      { wrong: '~~If it will rain~~', right: 'If it rains', why: 'После if в 1st conditional — Present Simple, will там не ставится (см. tenses.md, First Conditional).' },
    ],
    quiz: [ // НЕОБЯЗАТЕЛЬНО, но крайне желательно — 3-6 заданий на главу
      {
        type: 'mcq',
        prompt: 'If I ___ more time, I would learn Spanish.',
        options: ['have', 'had', 'will have', 'would have'],
        correctIndex: 1,
        explanation: 'Second Conditional: if + Past Simple, ... would + V.',
      },
      {
        type: 'fill',
        prompt: 'Переведи: «Если бы я знал, я бы сказал тебе».',
        answers: ['If I knew, I would tell you', 'If I had known, I would tell you'],
        explanation: 'Второе условие — про настоящее/будущее гипотетическое: if + Past Simple.',
      },
    ],
  },
  // ... остальные главы этого модуля
);
```

## Правила заполнения

- **id уникален по всему учебнику**, не только внутри файла — проверяется тестом `test/validate.js`.
- **module** — точная строка, одинаковая у всех глав одного модуля (иначе сайдбар разобьёт
  их на разные группы). Формат: `Модуль N. Название`.
- **focus** ставится, только если тема прямо связана с 🔴/🟡 правилом ученика из `rules.md`
  (дашборд в начале файла) — не придумывать слабые места, которых нет в дашборде.
  `focusNote` в этом случае должен упоминать номер правила.
- **intro** — по-русски (объяснение), примеры — по-английски, с переводом там, где перевод
  добавляет ясность. Тон — как в `rules.md`/`tenses.md`: конкретно, "почему", а не общие слова.
- **mistakes** — только реальные примеры из `rules.md`/`errors_log.md`, дословно или близко
  к дословному. Не для общих C1-тем (conditionals, passive и т.п.), где таких примеров нет —
  там поле просто не указывается.
- **quiz** — придуманные, но грамматически безупречные задания. `fill` сравнивается регистронезависимо
  и с обрезкой пробелов; если возможны несколько верных ответов — перечислить все в `answers`.
- Никакого HTML вне `intro` не должно ссылаться на классы, которых нет в `style.css`
  (`callout`, `callout warn`, таблицы — стандартные теги, это всё уже стилизовано).
